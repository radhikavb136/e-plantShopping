# e-plantShopping

## Project: e-plantShopping
Paradise Nursery is a React plant-shopping application where customers can browse indoor plants, explore categories, add plants to a shopping cart, change quantities, and review their order total.

## Features
- Landing page with “Welcome to Paradise Nursery” and a Get Started button
- About Us information
- Plant categories and product cards
- Redux-powered shopping cart
- Add, remove, and update quantity actions
- Cart item count and order total

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.
